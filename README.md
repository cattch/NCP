# NVIDIA Color Preset (NCP)

어두운 게임에서 적이나 주변 환경을 더 잘 보기 위해 밝기·감마·디지털 바이브런스·ICC 등을 조절하지만, 게임이나 상황이 바뀔 때마다 다시 설정하기는 번거롭습니다. **NCP는 화면 색상 설정을 프리셋으로 저장하고, 클릭 한 번으로 전환하는 Windows용 프로그램입니다.** 여러 프리셋을 프로필로 묶어 관리할 수도 있습니다.

## 주요 기능

- 밝기·대비·감마·디지털 바이브런스·색조 및 ICC 프로필 저장
- 프리셋별 적용 버튼, 드래그로 목록 순서 변경
- 기본값 프리셋 삭제 및 **기본값 추가** 버튼으로 복구·중복 추가
- 여러 프리셋을 묶은 프로필 관리와 ICC를 포함한 내보내기·불러오기
- 설정과 ICC 백업을 프로그램 폴더 안에서 관리
- 선택한 모니터를 기억해 다음 실행에도 유지

## 안전성

**NCP가 조절하는 대상은 모니터로 내보내는 화면의 색상 설정입니다.** NVIDIA 제어판의 바탕화면 색상 조절과 Windows 색 관리에서 다루는 디스플레이 출력 영역에 적용됩니다.

| 설정 | 실제로 변경하는 영역 |
| --- | --- |
| 밝기·대비·감마 | NVIDIA 드라이버의 모니터별 출력 보정 곡선입니다. 밝기 단계별 색상 변환표인 **감마 LUT**를 바꿔 화면에 보이는 밝기와 명암을 조절합니다. |
| 디지털 바이브런스·색조 | NVIDIA 드라이버의 해당 모니터에 대한 채도·색조 보정 설정입니다. |
| ICC | Windows 색 관리에서 해당 모니터에 연결하는 색상 보정 프로필입니다. 기본 프리셋의 ICC는 어두운 부분을 밝히고 이미 밝은 부분은 과하게 밝아지지 않도록 보정해, 눈부심을 줄이면서 암부를 구분하기 쉽게 합니다. |

게임이 만든 화면을 모니터에 출력하는 단계의 색상을 조절하며, 게임 파일·실행 프로세스·메모리에 접근하거나 게임에 코드나 필터를 삽입하지 않습니다. 게임 감지·자동 전환·핫키 기능도 없습니다. 동작 범위는 [NVIDIA의 바탕화면 색상 설정](https://www.nvidia.com/content/Control-Panel-Help/vLatest/en-us/mergedProjects/Display/CS_Adjust_Color_Settings_Advanced.htm) 및 [Windows의 모니터 ICC 연결](https://learn.microsoft.com/en-us/windows/win32/api/icm/nf-icm-wcsassociatecolorprofilewithdevice)과 관련된 영역입니다.

제작자의 사용 환경에서는 워독스·에이펙스·타르코프 등과 NCP를 함께 실행했을 때 게임 강제 종료나 동시 실행 차단을 경험하지 않았습니다. 이는 해당 환경에서의 사용 경험이며, 게임별 허용 기준은 각 게임의 운영 정책을 따릅니다.

외부 프로그램 감지로 인한 오인이 마음에 걸린다면, **게임 실행 전 프리셋 적용 → NCP 종료 → 게임 실행** 순서로 사용할 수도 있습니다. 설정은 드라이버와 Windows에 적용되므로 NCP를 종료해도 자동으로 원복하지 않습니다.

## 사용법

1. **Releases**에서 실행용 ZIP을 내려받아 압축을 풀고 `NCP.exe`를 실행합니다.
2. 사용할 모니터를 선택하고 원하는 프리셋 옆의 **적용**을 누릅니다.
3. 직접 조절하려면 프리셋을 추가하거나 값을 수정한 뒤 **변경 저장**을 누릅니다. 저장하면 바로 적용됩니다. 필요하면 ICC도 불러올 수 있습니다.
4. 기본 색상 설정으로 돌아가려면 **기본값**을 적용합니다. 목록에서 삭제했다면 **기본값 추가**로 다시 넣을 수 있습니다.

Windows 11에서 ICC 보정이 반영되지 않으면 디스플레이 설정에서 해당 모니터의 **앱의 색 자동 관리**를 끈 뒤 다시 적용해 보세요. 이 옵션을 항상 꺼야 하는 것은 아니며, 일반적인 색 정확도를 위한 Windows 기능입니다.

## 기본 포함 프리셋

| 프리셋 | 용도 |
| --- | --- |
| 기본값 | 밝기 50 · 대비 50 · 감마 1.00 · 디지털 바이브런스 50 · 색조 0으로 복귀하고 NCP의 ICC 연결을 해제합니다. |
| 맑음 | 맑은 날씨에 사용합니다. |
| 흐림 & 안개 & 비 | 흐림, 안개, 비가 오는 날씨에 사용합니다. |
| 야간 | 극도로 어두운 야간에 사용합니다. |
| 범용 | 어둡지 않은 캐주얼한 게임에서 사용합니다. |

모니터와 게임에 따라 보이는 결과가 다르므로 필요에 맞게 조절해 사용하세요. 기본 구성을 다시 불러오려면 **초기 프로필 추가**를 누르면 됩니다.

**사용 환경:** Windows 10/11 64비트, NVIDIA GPU에 연결된 모니터, NVIDIA 드라이버, .NET Framework 4.8.
